# Client configurations

`claude-code.mcp.json` goes in a project's `.mcp.json` (or `claude mcp add-json cadfork '<the cadfork object>'`), `cursor.mcp.json` in `~/.cursor/mcp.json`, and `codex.config.toml` in `~/.codex/config.toml`. Replace the three paths. Drafted by deepseek/deepseek-v4-flash, checked by hand.
