# F6 fixtures and evals

Everything here runs through `FreeCADCmd` with `QT_QPA_PLATFORM=offscreen`; nothing opens the GUI.

| File | What |
|---|---|
| `refactor_builders.py` | Small PartDesign documents for the unit tests |
| `corpus_build.py`, `corpus_worker.py`, `corpus_run.py` | The corpus run: every refactor op under `invariant()` on every document, a sabotage control, and the F3 reject check |
| `fetch_library.py`, `results/freecad_library_manifest.json` | 64 public FreeCAD-library files (pinned commit, sha256 per file); not stored in the repository |
| `agent_tasks.py` | Deterministic task banks: 100 macro tasks (20 families x 5 parameter sets, expected values from closed-form geometry) and 100 refactor tasks (10 task kinds over the 13 scripted models) |
| `agent_eval.py`, `agent_eval_worker.py`, `llm.py` | The 100 x 5 agent evals; `llm.py` is a small OpenRouter client that sums tokens and cost |
| `results/` | `corpus.json`, `macro_agent_eval.json`, `refactor_agent_eval.json` and the task lists |

## Corpus run (`results/corpus.json`)

201 documents: 78 scripted (13 golden models plus 5 parameter variants each), 59 upstream FreeCAD `.FCStd`, 64 FreeCAD-library files. 184 are clean (their no-op control run recomputes without errors): 78 scripted, 55 upstream, 51 library, so 106 real files. The 17 excluded are named in the file (15 unclean on a plain open, 2 not valid archives).

| Op | Documents | Invariance passes | Documents the op changed | Changes |
|---|---:|---:|---:|---:|
| relabel | 184 | 184 | 176 | 967 |
| lift into VarSet | 184 | 184 | 146 | 891 |
| lift into Spreadsheet | 184 | 184 | 146 | 891 |
| apply across bodies | 184 | 184 | 94 | 117 |
| merge redundant (no-ops injected first) | 184 | 184 | 72 | 88 |

920/920 invariance passes, with no lift cap. Documents where an op had nothing to change still count as passes; the "changed" column says how many were not vacuous. Sabotage (a deliberate 1% size change or a 0.01 mm move) was detected on 171/171 applicable documents.

F3 reject (all ops inside one `AgentTurn` with a snapshot store, then `reject()`): 184/184 documents identical (106/106 real), against merged `agent/F3-diff` at `c6d4ae7390` ("snapshot reject keeps the human's redo; unreached documents roll back by undo"). The earlier run, against an older F3, had 8 documents that were not restored (six `m10_linear_pattern` variants, `ArchDetail`, `BIMExample`); the `reject_baseline` control, which does the same kind of edit with plain FreeCAD calls and no F6 code, failed on the same eight, so that was F3's undo and not a refactor, and the F3 fix removed it. `results/corpus.json` lists any failure under `per_op.reject.attribution` (now empty on both sides).

The merge column counts only the injected no-op patterns: the run checks that every removed object is one of them. The conservative merge rules (SAFETY.md R8 to R10) leave all real features alone, including `Pocket001` of the upstream `data/tests/PocketTest.fcstd`, an `UpToFace` pocket the first merge rule removed.

## Agent evals

Both use `deepseek/deepseek-v4-flash` through OpenRouter; each result file ends with a footer line of calls, tokens and cost. Tasks and their check expressions are generated by `agent_tasks.py`, not by a model. **The check expression is never shown to the model**: the prompt carries the task in words (names, sizes, placements, expressions) and says only that a hidden test inspects the document afterwards; a failed run is fed back as "ran but did not satisfy the task" without the expression.

Macro eval (`results/macro_agent_eval.json`): 100 tasks x 5 passes at the script's default of 3 rounds (the first attempt plus up to two repairs). The model writes a macro, pyright runs before execution and a rejected macro is never run, a clean macro runs headless and its check must hold; a failure is fed back. Run of 2026-10-27: first attempt 399/500 (79.8%), 490 after one repair (98.0%), 500/500 after two (100%); 0 macros executed without a clean pyright result. 48 first attempts were rejected by pyright (now including invented `TopoShape` attributes, see `refactor/grounding.py`), 53 raised at run time, none ran to a false check. Cost $0.0333 (611 calls).

Refactor eval (`results/refactor_agent_eval.json`): 100 tasks x 5 passes, single shot. The model writes `edit(doc)` from a listing of the document and the refactor API; it runs under `invariant()` and then the task check. 450/500 pass (90.0%); 34 script errors (13 in `across_bodies`, 17 in `lift_pads_sheet`, mostly invented Spreadsheet methods), 9 edits changed the geometry and were caught and rolled back with `restored_identical` true, 7 left the geometry alone but did not do what the task asked. No check was already true before an edit. Cost $0.0128 (500 calls). The checks are stricter than in the first version: `lift_all_*` require that at least as many properties as the reference `lift_all` binds now carry an expression that reads the `Parameters` container (an empty container no longer passes), and `across_bodies` requires every body to have at least the reference count of expressions that read a Spreadsheet or VarSet; tasks for documents where the reference binds nothing are dropped, so none is vacuous. The earlier 482/500 (96.4%) was measured with the weaker checks and with the check expression in the prompt, and should not be compared with this run.

How the macro prompt was tuned, because it was tuned on this task set: a first version reached 89.6% (ambiguous box-dimension wording in 6 task texts), then 87.8% (wording fixed), 94.8% (verified PartDesign patterns added to the prompt) and 100% (pattern text corrected after the models copied a corner pin from it); those runs showed the check expression and used 4 rounds. The 2026-10-27 run above is the first at the default 3 rounds with the expression hidden. The 100% after two repairs is still an in-sample figure for this task bank (the prompt patterns were tuned on it); the first-attempt rate of 79.8% is the better guide to unseen tasks.
