# F6 fixtures and evals

Everything here runs through `FreeCADCmd` with `QT_QPA_PLATFORM=offscreen`; nothing opens the GUI.

| File | What |
|---|---|
| `refactor_builders.py` | Small PartDesign documents for the unit tests |
| `corpus_build.py`, `corpus_worker.py`, `corpus_run.py` | The corpus run: every refactor op under `invariant()` on every document, a sabotage control, and the F3 reject check |
| `fetch_library.py`, `results/freecad_library_manifest.json` | 64 public FreeCAD-library files (pinned commit, sha256 per file); not stored in the repository |
| `agent_tasks.py` | Deterministic task banks: 100 macro tasks (20 families x 5 parameter sets, expected values from closed-form geometry) and 100 refactor tasks (10 task kinds over the 13 scripted models) |
| `agent_eval.py`, `agent_eval_worker.py`, `llm.py` | The 100 x 5 agent evals; `llm.py` is a small OpenRouter client that sums tokens and cost |
| `results/` | `corpus.json`, `macro_agent_eval.json`, `refactor_agent_eval.json` and the task lists |

## Corpus run (`results/corpus.json`)

201 documents: 78 scripted (13 golden models plus 5 parameter variants each), 59 upstream FreeCAD `.FCStd`, 64 FreeCAD-library files. 184 are clean (their no-op control run recomputes without errors): 78 scripted, 55 upstream, 51 library, so 106 real files. The 17 excluded are named in the file (15 unclean on a plain open, 2 not valid archives).

| Op | Documents | Invariance passes | Documents the op changed | Changes |
|---|---:|---:|---:|---:|
| relabel | 184 | 184 | 176 | 967 |
| lift into VarSet | 184 | 184 | 146 | 891 |
| lift into Spreadsheet | 184 | 184 | 146 | 891 |
| apply across bodies | 184 | 184 | 94 | 117 |
| merge redundant (no-ops injected first) | 184 | 184 | 72 | 89 |

920/920 invariance passes, with no lift cap. Documents where an op had nothing to change still count as passes; the "changed" column says how many were not vacuous. Sabotage (a deliberate 1% size change or a 0.01 mm move) was detected on 171/171 applicable documents.

F3 reject (all ops inside one `AgentTurn` with a snapshot store, then `reject()`): 176/184 documents identical (104/106 real). The 8 that are not identical (six `m10_linear_pattern` variants, `ArchDetail`, `BIMExample`) also fail the `reject_baseline` control, which does the same kind of edit with plain FreeCAD calls and no F6 code, so the cause is F3 or FreeCAD's undo of `LinearPattern` Spacings lists and a few Arch properties, not a refactor. `results/corpus.json` lists them under `per_op.reject.attribution`.

## Agent evals

Both use `deepseek/deepseek-v4-flash` through OpenRouter; each result file ends with a footer line of calls, tokens and cost. Tasks and their check expressions are generated by `agent_tasks.py`, not by a model.

Macro eval (`results/macro_agent_eval.json`): 100 tasks x 5 passes. The model writes a macro, pyright runs before execution and a rejected macro is never run, a clean macro runs headless and its check must hold; a failure is fed back for up to 4 rounds. Final run: first attempt 413/500 (82.6%), 484 after one repair, 500/500 after three; 0 macros executed without a clean pyright result.

Refactor eval (`results/refactor_agent_eval.json`): 100 tasks x 5 passes, single shot. The model writes `edit(doc)` from a listing of the document and the refactor API; it runs under `invariant()` and then the task check. 482/500 pass; 17 script errors (mostly invented Spreadsheet methods); 1 edit changed the geometry and was caught and rolled back with `restored_identical` true. No check was already true before an edit.

How the macro numbers came about, because the prompt was tuned on this task set: 89.6% (first version, ambiguous box-dimension wording in 6 task texts), 87.8% (wording fixed), 94.8% (verified PartDesign patterns added to the prompt), 100% (pattern text corrected after the models copied a corner pin from it). The first-attempt rate rose from 62% to 83% over the same steps. Treat 100% as the pipeline's ceiling on this bank, not as an out-of-sample rate.
